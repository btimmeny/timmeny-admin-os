## Scope

This document will define the canonical architecture of Timmeny Admin OS, including:

- reasoning-provider boundary
- Timmeny Admin OS core responsibilities
- context assembly
- workflow and policy execution
- learning and goal intelligence
- recurrence and automation
- identity mapping and synchronization
- audit history
- external capability adapters
- ownership boundaries among Monday.com, PostgreSQL, Gmail, Calendar, Git, and AI providers

The existing `docs/architecture.md` remains implementation-specific reference material until this canonical architecture document is completed and reconciled with it.
