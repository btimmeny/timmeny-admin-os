# Source Snapshots

This directory holds source artifacts or indexes used to curate the operating model, including screenshots of Monday.com views.

A snapshot is evidence of what an external system displayed at a point in time. It is not automatically canonical and should not be imported blindly.

For each processed snapshot, record when practical:

- snapshot ID
- source system
- captured date and time
- scope or view
- processing status
- Actions, Outcomes, Obligations, Entities, Decisions, or Evidence created or updated from it
- unresolved cleanup or classification questions

Images may be stored here when appropriate. Never treat an unprocessed screenshot as authoritative operating state.
